# Korea4 — Free-Time Vacation Planner (SF Bay Area radio sports)

**Live site:** https://karagemop466-tech.github.io/Korea4/

When is it free? A minute is free only when no MLB game (all 30 clubs), no NFL game, no Stanford/Cal football game, and no Westwood One national NFL broadcast is on air.

**Headline finding:** No 1-, 2- or 3-week fully-free window exists in 2027–2029 under that strict definition. Best window: **Feb 15–18, 2027** (4 days, verified anchors); ~4–5 estimated days each Feb 2028 & 2029. See `site/` (GitHub Pages), `docs/sources.md`, `docs/vacation-windows.md`, `docs/radio.md`, `docs/flagged.md`, and `COORDINATION.md`.
