# FREE TIME VACATION — Bay Area Radio Free-Time Dashboard

**Live site:** https://karagemop466-tech.github.io/Korea4/

> Find when you're *actually* free to leave town and miss nothing on Bay Area AM/FM radio.
> Outer Sunset SF 94122 • PST • Only AM/FM counts.

**A minute is free when none of these are on air:**
- MLB (all 30 clubs; Giants & A's high priority — preseason/regular/postseason/All-Star)
- NFL — all 32 (+ 49ers high priority — preseason/regular/postseason)
- NCAAF — Stanford Cardinal & California Golden Bears (high priority)
- Westwood One Sports national NFL radio (TNF/SNF/MNF + playoffs + Super Bowl)

## Quick Start — Best Vacation Window

| Year | Best 2-week window | Status | Basis |
|------|--------------------|--------|-------|
| **2026** | **Feb 9–22** (Mon–Sun, 14 days) | ✅ Verified | Super Bowl Feb 8 → spring training Feb 24 — no radio sports |
| 2027 | Feb 8–21 (est) | 🔶 Estimated | Same post-Super Bowl pattern |
| 2028 | Feb 7–20 (est, leap year + LA Olympics) | 🔶 Estimated | Same — no 21-day window exists |
| 2029 | Feb 5–18 (est) | 🔶 Estimated | Same |

**Why February?** MLB runs Mar 25–Sep 27 daily (only All-Star 3-day break), NFL Sep–Feb (Westwood One makes every primetime night busy), NCAAF Sep–Nov. Only 14-day gap is post-Super Bowl → spring training. See [Vacation Windows](https://karagemop466-tech.github.io/Korea4/site/pages/vacation-windows.html).

**Alternate relaxed rule:** Ignore MLB spring training (preseason) → Feb 9 → Mar 24 = 44 days in 2026 (verified). Most travelers do this.

## Verification

- **Every table row must have a source link to an official site.** If a value can't be confirmed, it's blank and flagged as unverified. Never inferred.
- **2026 = verified** from official releases (MLB Aug 26 2025, NFL via legion/printablepedia, ACC via WriteForCalifornia/Wikipedia).
- **2027-2029 = estimated** per 15-year historical pattern, flagged `ESTIMATED` everywhere — never shown as verified.
