How to review these

  1. Sort by priority. P1 items unblock measurement; P2 items improve the data; P3 items improve the site.
  2. Check the measurement. If a suggestion has no measurable success condition it should not be accepted.
  3. Accept in order of blocking power. The four blocking items are results capture, injury snapshots, the market-line decision and the refresh trigger.
  4. Record the decision. Use the decision register so the reasoning survives.
