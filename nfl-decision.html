Read this first

Three things are true at once. (1) The NFL's own injury report and depth charts are rich enough to describe who is missing and who is next up — that part of this section is verified and linked. (2) The league publishes no betting lines, no effect sizes and no scoring baseline, so an originated line cannot be computed without inventing numbers; the worksheet page shows exactly which inputs exist and which do not. (3) Because the repository stores no final scores and no prices, zero strategies can currently be shown to be skill-based, so the leaderboard is empty and every correlation cell is blank.

What this section does not claim

  • No profit, edge, or win rate for any strategy.
  • No correlation value for any pair of legs (all eight register entries are blank with a stated reason).
  • No effect size for a missing starter, because no official source publishes one.
  • No identification of a 3rd/4th-string player at the 9 slots where the official chart lists no backup at all.
  • No "best path" — the decision register lists the paths and the evidence, not a verdict.
