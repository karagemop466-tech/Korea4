How correlation will be measured (pre-registered)

  1. Unit of observation — one game (for same-game pairs) or one slate (for cross-game pairs). Never both in the same estimate.
  2. Statistic — Pearson on the standardised outcome of each leg; reported with a bootstrap 95% interval, because these samples are small.
  3. Decision rule — a combo is re-priced using the measured value. If |rho| exceeds the pre-registered threshold (proposal: 0.30, decision D-08) the combo is rejected unless its joint edge still survives the re-price.
  4. No look-ahead — the correlation used to price week n may only use legs settled before week n.
  5. Reported even when zero — a measured near-zero value is published, because "independent" is a finding, not an assumption.
