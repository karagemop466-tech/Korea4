What this section is, and what it is not. It is the requirements, open questions, suggestions and strategy specifications for originating NFL lines and running a scored strategy competition. It is not a results page: this repository contains no market prices and no settled bets, so every result column in this section is blank by rule (IR-035). Nothing here has been implemented from the suggestions list beyond documentation, because each such item needs an owner decision.
How this relates to the other NFL pages on this site. Four workstreams now cover adjacent ground: the merged line-origination, strategies, injuries and suggestions module; the nfl-decision section with its own gate; and this section, whose job is the register layer — requirements with acceptance tests, the question set that gates a decision, the suggestions backlog that no one has approved yet, and the source registry behind every value. Where the same Week 10 injury report appears in more than one place, the difference is coverage, not contradiction: this section publishes only rows it can re-derive from a retrieval it recorded, and says so on the injury page. Nobody has ruled which section is canonical — that is SG-21 (flagged as IR-041).
