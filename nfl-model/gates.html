Validation gates

The tests every strategy must pass before it is funded, published or rewarded - written so that a passing strategy is a strategy, not a streak.

Design intent: a gate is a test a strategy cannot pass by having a good month. Where a gate depends on a number this repository does not have, that is stated in its 'needs' field rather than smoothed over.

Gate set

BLOCKING gates stop funding; REQUIRED-EVIDENCE gates stop publication; ADVISORY gates are displayed only.

G-09Minimum sample by effect size, not by convenienceBLOCKINGn must satisfy the pre-registered required-n for the claimed edge (normal-approximation two-sided 5%, 80% power, plus a season-block bootstrap interval), or the strategy is labelled INSUFFICIENT-DEMOGRAPHIC and stays unfunded.
