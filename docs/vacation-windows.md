# Vacation windows 2027–2029

Definition (strict, as requested): a minute is FREE only when none of these are on air — any MLB game (all 30 clubs, incl. preseason/spring, regular, All-Star/special, postseason), any NFL game (incl. preseason, Pro Bowl, postseason), Stanford NCAAF, Cal NCAAF, and Westwood One national NFL broadcasts (Thu/Sun/Mon night + specials + all postseason — these are NFL games, counted once).

## Bottom line
**No 1-week, 2-week, or 3-week fully-free window exists in 2027, 2028, or 2029 under this strict definition.** MLB occupies mid-Feb–Oct, NFL occupies Aug–mid-Feb, NCAAF occupies late-Aug–Jan, and they overlap/chain with only one recurring gap: between the Super Bowl and the first spring-training games in February. That gap is days, not weeks.

## If you relax ONE rule (scenario, not a verified schedule)
Dropping *spring training* only (regular-season MLB still counts) would extend the February window from the day after the Super Bowl to Mar 23, 2027 (day before Opening Night) — about 5 weeks in 2027. This is a scenario calculation from the verified anchors in sources.md #1/#7, not a claim that no other in-scope events occur then (NFL Combine etc. are not games and are out of scope). Equivalent estimated windows: mid-Feb–late-Mar 2028 and 2029 (ESTIMATED, schedules unreleased).

## Method & limits
Season-level analysis from verified anchor dates only. A game-by-game ingest of all 2,430 MLB games + all NFL games for 2027–2029 was NOT verified line-by-line in this session: 2027 MLB dates/opponents are released (times largely TBA), 2028/2029 MLB and 2027+ NFL schedules are unreleased, so no honest game-level table can be published yet. See Flagged page. During an active MLB season there are also isolated team off-days, but with all 30 clubs counted there is a game on effectively every day except the All-Star off-day — that is exactly why the July window is only 1 day.
