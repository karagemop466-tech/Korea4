Definition used on this page

A day is FREE only when the snapshot contains no block of any class for it. A day with a published game, an officially anchored all-day event of unknown start time, or only the released-season model does not count as free. This is stricter than asking whether some minutes are free.

Day classMeaning
PUBLISHED_OFFICIALAt least one published official game row (official start + estimated duration, official network window, or official date with TBD start).
UNVERIFIED_ANCHORNo published time, but an officially anchored event occupies the whole day (e.g. Super Bowl, CFP championship, dated college game).
MODEL_ONLYOnly the clearly-labelled 364-day model of unreleased seasons. Still treated as a candidate block.
NO_BLOCKNo block at all in the snapshot.
