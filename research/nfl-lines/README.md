# NFL Lines Lab — data and pipeline

Scope: own-line model, strategy backtest with validation gates, correlation and parlay analysis, an official injury-report snapshot, and the static site under `/lines/`.

## Inputs (provenance)
| File | What | Source | Status |
|---|---|---|---|
| `raw/games.csv.gz` | Game results, closing spread and total, rest days, roof, 1999–2026 | nflverse/nfldata `data/games.csv`, upstream commit `7aae940` (2026-11-13) | third-party, UNVERIFIED lines; 16 scores checked against NFL.com |
| `raw/closing_lines.csv.gz` | Closing lines by book (coverage review only) | nflverse/nfldata `data/closing_lines.csv` | third-party, UNVERIFIED |
| `official/nfl_2026_week9_final_scores.csv` | 16 final scores (Week 9 all 15 games + Week 10 Thursday) | NFL.com game pages linked in the file | VERIFIED |
| `official/nfl_injury_report_2026_week10.csv` | 9 game-status designations + 7 news-vs-table discrepancies | NFL.com injury report (https://www.nfl.com/injuries/) and NFL.com news headlines | VERIFIED (designations) / FLAGGED (discrepancies) |
| `manifest.json` | SHA-256 and byte counts for every file here | generated by `scripts/nfl_lines/build_site.py` | — |

The raw nfldata file was downloaded from `https://codeload.github.com/nflverse/nfldata/tar.gz/refs/heads/master` (sha256 of the tarball `ab3bc17f…`). Verify with `zcat raw/games.csv.gz | sha256sum` against the manifest.

## Pipeline (run in order)
```bash
python3 -m venv .venv-nfl && .venv-nfl/bin/pip install -r requirements-nfl-lines.txt
.venv-nfl/bin/python scripts/nfl_lines/model.py          # walk-forward ratings -> analysis/predictions.csv
.venv-nfl/bin/python scripts/nfl_lines/backtest.py       # strategies, gates, correlation, parlays -> analysis/backtest.json
.venv-nfl/bin/python scripts/nfl_lines/build_site.py     # static pages under lines/ and manifest.json
.venv-nfl/bin/python scripts/nfl_lines/verify_lines.py   # links, allowed hosts, row-level source links
.venv-nfl/bin/python -m unittest tests.test_nfl_lines    # unit tests and leakage test
```

## Outputs
- `analysis/predictions.csv` — one row per regular-season game from 2005; model margin and total use only earlier games.
- `analysis/backtest.json` — strategy statistics, gates, season ROI, correlations, parlays, model diagnostics.
- `analysis/bets.csv` — per-bet log; **not committed** (2.4 MB, reproducible; listed in `.gitignore`).
