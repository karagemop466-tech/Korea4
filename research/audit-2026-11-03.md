# Independent safety audit — November 3, 2026

## Executive summary

The existing site is a planning aid, **not a certificate of broadcast-free time**. No fully verified 7-, 14-, or 21-day vacation window in 2027, 2028 or 2029 has been established. This does not prove such windows cannot exist. Previously ranked windows remain scenarios, not booking recommendations.

The prior source snapshot is dated November 2. This session has restricted outbound access and has not newly retrieved the official league/station websites. Existing VERIFIED labels refer to previously captured fields; neither a URL nor an HTTP 200 validates its contents. The audit preserves the prior evidence and does not invent replacement game data.

## Findings and changes

- Empty/filtered daily data previously displayed “FREE ALL DAY”; now it explicitly says UNKNOWN. Daily gaps previously called exact are labelled estimated planning gaps.
- Every primary page now warns that schedules, actual durations and game-specific terrestrial carriage are incomplete. The Flagged for Review page explains the limitations with official links.
- All MLB/NFL rows are conservative personal conflicts, not a claim every game can be heard on Bay Area AM/FM. WWO affiliates do not necessarily air every network event. Official [WWO station finder](https://www.westwoodonesports.com/station-finder/) and [NFL network schedule](https://www.westwoodonesports.com/nfl-schedule/) are manual-review references, not newly checked evidence.
- Per-day duration overrides incorrectly extended already-split overnight fragments. Removed overrides; retained the source model and its estimates. Schedule entry remains automatic.
- Today navigation now uses the current Pacific date instead of the snapshot date.
- Local wall-clock complements are not exact elapsed durations on DST days. Warnings disclose this; a full DST-safe primary-engine migration remains outstanding. Archived planner engine DST tests are not proof the primary renderer is DST-safe.
- Other Bay Area live sports and station pre/postgame programming are not exhaustively established. Unknown reception in Outer Sunset remains flagged.
- Verification formerly inspected only rows already having source attributes, permitting missing attributes to evade checks. It now examines every primary tbody row and requires the declared URL to match a visible link.
- Verification now checks all 675 stored official response hashes and uncompressed lengths and official-domain membership of all 6,607 event sources. This establishes integrity/provenance structure, **not factual accuracy of every field**. Review-page historical nonofficial references are deliberately retained and flagged.

## Remaining needs review

Fresh official-source content verification; exhaustive game-specific Bay Area AM/FM carriage; 2027–2029 future schedule releases; broadcast overruns and actual ends; DST elapsed-time arithmetic; reception testing. These limitations do not prevent publishing a clearly labelled planning aid.

## Additional provenance defect corrected

Nine 49ers rows pointed to a ticket reseller CTA (including a truncated URL), despite their values coming from the captured official schedule. These now cite https://www.49ers.com/schedule/. The parser always cites its actual schedule evidence instead of blindly trusting a CTA. The stored official schedule cards were read locally to confirm the matching game IDs and kickoff values, including Jan. 3, 2027; this is snapshot cross-checking, not a fresh site fetch. One historical NFL PDF was captured via HTTP on media.nfl.com; integrity is checked but transport is not authenticated by the hash.
