How intraday free time is computed

For each game we create a radio window = pregame + game + halftime. Example: Giants 1:35 PM PT start → window 1:05 PM – 4:35 PM (30 min pre + 168 min game + 15 post). 49ers 5:15 PM PT → 4:15 PM – 9:00 PM (60 pre + 192 game + 30 post). Any minute inside any window = busy. Gaps between windows = free slices we show.

Averages: MLB 2:48–3:10 2024 3:10 source, NFL 3:12 Nielsen, NCAAF 3:27 2024 FBS. See methodology.
